# 生命游戏与图案 

程序实现了经典的康威生命游戏。** Conway's Game of Life, running in a browser and programmed in JavaScript **


## 功能特性

- 规则B3/S23，即 3个邻居诞生1个活细胞，2-3个邻居则继续存活，其他情况则因孤独或拥挤而死。
- 画布尺寸601x601=361,201px，每个像素代表一个细胞，黑色为活，白色为死，随着代代演变，图形发生有规律的变化，可形成各式各样精美图案。
- ADD PATTERN 添加图案
    <p>可选同心圆、正方形、正三角、网格、对角线、斜向圆圈、方块、随机马赛克等结构化图案，叠加至画布并铺满，图形递进的间隔、间隔的调整增量由SPACING和ADJUST控制。</p>
    <p>🔼 SPACING 间隔 - 图案线条之间的间距，范围 [2, 200]，默认为20px.</p>
    <p>🔽 ADJUST 调整 - 间隔的增量，范围 [-100, 100]，默认为0，即等间距。同时，程序控制Ad不超过S/2，或取绝对值，防止间隔过大或过小导致显示异常。</p>
    <p>注意，Blocks图案的S=实心方块大小，Ad+1=间隔；Mosaic图案的S=方块大小，最大32px，Ad~控制密度 [5%, 70%]。例如，PATTERN(blocks, 32, 0)，相当于手工模式的棋盘。<p>
- 游戏控制
    <p><kbd>Space</kbd> - 运行/暂停 (PLAY/PAUSE) - 以指定速率演化（默认每秒1代），直到活细胞为0，或连续8代细胞数量不变即自动停止</p>
    <p><kbd>F</kbd> - 单步运行 (STEPPING)</p>
    <p><kbd>R</kbd> - 旋转画布 (ROTATE) - 顺时针90°循环</p>
    <p><kbd>Ctrl+R</kbd> - 重置画布 (RESET)</p>
- 编辑模式
    <p><kbd>P</kbd> - 画笔模式 (PAINT) - 单击添加1个半径r=2px的圆点，含13个活细胞</p>
    <p><kbd>E</kbd> - 擦除模式 (ERASER) - 64x64px 区域擦除</p>
    <p><kbd>M</kbd> - 放大镜模式 (MAGNIFY) - 120x120px 透镜，放大4倍，每1个原始细胞被放大显示为4×4像素的方块</p>
    <p><kbd>H</kbd> - 手工模式 (HANDMADE) - 棋盘大小为 18x18，每个格子 32x32px当作1个细胞，间隔线条 1px，即 19x19线的标准围棋棋盘 </p>
                            

## 安装使用

单个HTML文件，不需要安装，在浏览器中打开即可运行。

**方式一** 

下载本仓库中的 `index.html` 文件，双击用浏览器打开即可使用。

**方式二：在线使用**

直接访问：https://phdnext.github.io/life-game/
